# API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/health` | Server health |
| POST/GET | `/buildings` | Create/list buildings |
| GET | `/buildings/{id}` | Building details |
| POST/GET | `/apartments` | Create/list apartments |
| POST/GET | `/payments` | Create/list payments |
| POST/GET | `/expenses` | Create/list expenses |
| POST/GET | `/complaints` | Create/list complaints |
| PATCH | `/complaints/{id}` | Update complaint status |
| GET | `/dashboard` | Financial summary |

Open `/docs` for interactive API documentation.
